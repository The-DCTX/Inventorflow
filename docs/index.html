Fonctionnalités

Tout le cycle de vie du parc, centralisé

De l'inventaire à la facturation, pensé pour les prestataires IT et MSP qui gèrent plusieurs clients.

Inventaire du parc

CRUD complet des postes macOS / Windows / Linux avec historique d'assignation.

  • Série, CPU, RAM, stockage, IP, MAC
  • Statuts actif / stock / réparation / retiré
  • Nommage normalisé par templates + export CSV

Multi-client

Sélecteur de client en barre latérale, données isolées par client_id sur toutes les vues.

  • Clé de déploiement par client
  • Cloisonnement total des données

Supervision temps réel

Agent bash universel qui remonte CPU, RAM, disque, load, uptime chaque heure.

  • Température CPU multi-plateforme
  • Détection brute-force SSH + whitelist LAN
  • Heartbeat & alertes de sécurité

Licences logicielles

Catalogue HT / TTC avec prix d'achat, revente et marge.

  • Attribution par poste ou utilisateur
  • Barre de conformité (sièges utilisés)
  • Alertes de renouvellement J-90 / J-30

Facturation

Abonnements client ↔ service calculés automatiquement selon les ressources actives.

  • Services par poste, utilisateur, forfait, horaire
  • MRR / ARR et marge nette en continu

Pilotage & rapports

Tableau de bord à widgets personnalisables et rapports PDF double version.

  • Version interne (marges) / client (masquées)
  • Rôles superadmin / admin / viewer
  • Assistant d'offboarding employé

Installation

Déployé en quelques minutes

Installeur interactif et idempotent sur Debian 11+ / Ubuntu 22.04+ : détection de l'OS, dépendances, PHP-FPM, base de données, vhost et compte admin.

# 1. Installer le serveur
unzip inventorflow-deploy.zip -d if-install
cd if-install && sudo bash install.sh

# 2. Déployer l'agent sur un poste (clé générée par client)
curl -fsSL 'https://votre-serveur/deploy.php?key=CLE_CLIENT' | bash
